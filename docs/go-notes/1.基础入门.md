## Hello World

```go
package main

import "fmt"

func main() {
    fmt.Println("hello, world")
}
```

::: tip Go 程序结构
每个 Go 程序由以下部分组成：
1. `package` — 包声明，`main` 包是可执行程序的入口
2. `import` — 导入依赖包
3. `func main()` — 程序执行的入口函数
:::

## 变量声明

Go 有三种声明变量的方式：

```go
// 1. var 声明（默认为零值）
var a int          // 0
var name string    // ""
var flag bool      // false

// 2. var 声明并初始化
var weight = 23.4
var pi float64 = 3.14

// 3. 短声明 := （只能在函数内使用）
age := 18
count := 5
```

> [!NOTE]
> 短声明 `:=` 不能在 `for`、`if`、`switch` 语句外使用，且不能用于 package 级别。

### 多变量声明

```go
// 方式一：分组声明
var (
    one = 1
    two = 2
)

// 方式二：同行声明
var one, two = 1, 2

// 方式三：短声明（最常用）
one, two := 1, 2
```

### 零值（初始值）

Go 中变量声明后会自动赋予「零值」，不会出现未初始化变量：

```go
var a int        // 0
var b bool       // false
var c float32    // 0
var d string     // ""（空字符串）
```

## 常量

```go
// 常量定义时必须赋值，之后不可修改
const pi = 3.14

// 批量声明常量
const (
    num1 = 13
    num2 = 15
)
```

::: warning
Go 中的常量使用 `const` 关键字，一旦赋值就不能修改。
:::

## 基本数据类型

| 类型 | 说明 | 取值范围 |
|------|------|----------|
| `int` / `uint` | 平台相关（32/64位） | 32位或64位 |
| `int8` ~ `int64` | 有符号整数 | -128~127 到 -2^63~2^63-1 |
| `uint8` ~ `uint64` | 无符号整数 | 0~255 到 0~2^64-1 |
| `float32` / `float64` | 浮点数 | IEEE-754 |
| `byte` | uint8 别名 | 0~255 |
| `rune` | int32 别名，表示 Unicode 码点 | Unicode 字符 |
| `string` | 字符串 | — |
| `bool` | 布尔值 | `true` / `false` |

### 整数环绕

```go
var num1 uint8 = 255
num1++               // 绕回 0（uint8 范围 0~255）

var num2 int8 = 127
num2++               // 绕回 -128（int8 范围 -128~127）
```

### byte 与 rune

```go
var a byte = 'a'
fmt.Printf("%c 对应的 ASCII 值为 %d\n", a, a) // a 97

var z rune = '庞'
fmt.Printf("%c 对应的 Unicode 值为 %d\n", z, z) // 庞 24247
```

### 类型别名

```go
type myInt = int
var a myInt = 8
fmt.Printf("a 是 %T 类型，值 = %v\n", a, a) // int, 8
```

### ASCII 与字符打印

```go
var (
    pi    rune = 960
    alpha rune = 940
    bang  byte = 33
)
fmt.Printf("%c %c %c\n", pi, alpha, bang) // π ά !
```

## 格式化输出

| 格式化动词 | 说明 |
|:----------:|------|
| `%v` | 值的默认格式 |
| `%#v` | 值的 Go 语法表示（含引号、结构体字段名等） |
| `%T` | 值的类型 |
| `%c` | 字符（Unicode 码点） |
| `%d` | 十进制整数 |
| `%x` | 十六进制 |
| `%f` | 浮点数 |
| `%s` | 字符串 |

```go
fmt.Printf("%T\n", "hello") // string
fmt.Printf("%#v\n", "")     // ""（空字符串的完整表示）

// 将格式化后的内容赋值给变量
var op = fmt.Sprintf("%d", num1)
```

### 宽度与填充

```go
// 正数向右填充空格，负数向左填充
fmt.Printf("%-4vhello%4v\n", 12, pi)
// 输出: "12  hello3.14"

// 用 0 填充，指定宽度
fmt.Printf("color: #%02x%02x%02x\n", red, green, blue)
// 输出: color: #008dd5
```

## 输入输出

```go
var name string
fmt.Print("请输入你的名字：")
fmt.Scan(&name)
fmt.Println("你的名字是：", name)

// 带错误处理
var age int
_, err := fmt.Scan(&age)
fmt.Println(age, err)
```

### 命令行参数

```go
import "os"

func main() {
    var s, sep string
    for i := 1; i < len(os.Args); i++ {
        s += sep + os.Args[i]
        sep = " "
    }
    fmt.Println(s)
}
```

## 控制流

### if-else

```go
if v := math.Pow(3, 2); v < 10 {
    return v
} else {
    fmt.Printf("%g >= 10\n", v)
}
```

> `if` 后可以像 `for` 一样先执行一个简单语句，再判断条件。

### for 循环

Go 只有 `for` 循环，没有 `while` 或 `do-while`：

```go
// 标准 for 循环
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// 类似 while
for i < 10 {
    i++
}

// 无限循环
for {
    // ...
    break
}
```

### switch

```go
// 1. switch 表达式
switch time.Tuesday {
case today + 0:
    fmt.Println("今天")
case today + 1:
    fmt.Println("明天")
default:
    fmt.Println("其他")
}

// 2. switch 无表达式（类似 if-else 链）
switch {
case t.Hour() < 12:
    fmt.Println("上午好")
case t.Hour() < 17:
    fmt.Println("下午好")
default:
    fmt.Println("晚上好")
}

// 3. 检测操作系统
switch os := runtime.GOARCH; os {
case "darwin":
    fmt.Println("macOS")
case "linux":
    fmt.Println("Linux")
default:
    fmt.Println(os)
}
```

### 随机数

```go
import "math/rand"

// 随机 0~9
num := rand.Intn(10)

// 随机 1~10
num = rand.Intn(10) + 1
```
