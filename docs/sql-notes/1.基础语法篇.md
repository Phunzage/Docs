## 本章概览

本章是 SQL 学习的**起点**，带你从零掌握查询的基础语法。全章共 13 关（L1 ~ L13），分为三大部分：

- **查询基础（L1 ~ L4）**：全表查询、选择查询、别名、常量和运算 —— 学会「怎么把数据查出来」
- **条件查询（L5 ~ L9）**：`where` 子句、比较运算符、空值、模糊查询、逻辑运算 —— 学会「怎么筛选想要的数据」
- **查询进阶（L10 ~ L13）**：去重、排序、截断和偏移、条件分支 —— 学会「怎么整理和加工结果」

大部分关卡都基于一张学生表 `student`，包含字段：`id`（学号）、`name`（姓名）、`age`（年龄）、`class_id`（班级编号）、`score`（成绩）、`exam_num`（考试编号）。后面的关卡会在此基础上逐步叠加新的语法，建议按顺序学习、逐关动手敲一遍。

::: tip 学习方法
每一关都按「题目 → 参考答案 → 解析」的结构组织。建议先自己写一遍答案，再对照参考答案，最后看解析确认知识点是否掌握。
:::

### L1 全表查询

**题目**：从 `student` 表中查询出所有学生的全部信息。

**参考答案**：

```sql
select * from student
```

**解析**：`SELECT` 是 SQL 的查询关键字，`*` 是一个通配符，代表数据表中的**所有列**。`FROM student` 指定了要查询的数据表。整句的意思就是：把 `student` 表中每一行的所有字段都查出来，这是最简单直接的查询方式，也是学习 SQL 写出的第一条语句。

可以把数据库想象成一座大型图书馆：数据库就是图书馆，数据表是图书馆里的书架，表中的每一行是一本书，每一列是书的属性（书名、出版日期等）。全表查询，就相当于把整排书架上的书从头到尾浏览一遍。

::: tip 知识点
`SELECT * FROM 表名` 就是**全表查询**。`*` 表示「所有列」，不需要提前知道表里有哪些字段，适合快速浏览整张表的数据。
:::

::: warning 注意
`*` 虽然方便，但在生产环境中建议尽量**显式列出需要的列**。一是结果集更小、传输更快，二是表结构变化时查询结果更可控。
:::

### L2 选择查询

**题目**：从 `student` 表中选择出所有学生的姓名（name）和年龄（age）信息，姓名在前、年龄在后。

**参考答案**：

```sql
select name, age from student
```

**解析**：与全表查询不同，选择查询在 `SELECT` 后面**明确列出需要的列名**，用逗号分隔，数据库只会返回这些列的数据。这样做既能减少不必要的数据传输，也能让查询意图更清晰。

举个例子：你是一名班级管理者，名单表上列有姓名、年龄、性别、分数等信息，而你现在只需要了解学生的姓名和年龄，那么只需从表中挑出这两列即可，其余列一概不返回。

::: tip 知识点
`SELECT 列1, 列2, ... FROM 表名` 就是**选择查询**：只返回指定的列。结果列的**输出顺序**由 `SELECT` 后列名的书写顺序决定，所以题目要求姓名在前、年龄在后时，必须写成 `select name, age`。
:::

### L3 别名

**题目**：从 `student` 表中选择学生的姓名（name）和年龄（age），并分别取别名为「学生姓名」和「学生年龄」。

**参考答案**：

```sql
select name as 学生姓名, age 学生年龄 from student
```

**解析**：别名给查询结果中的列起一个**临时的、可读性更高的名字**，它不会改变表本身的结构。标准写法是 `列名 as 别名`，其中 `as` 关键字可以省略（如 `age 学生年龄`），两种写法等价。

打个比方：你是团队领导，为了更好地管理，给每位成员起了昵称。昵称并不改变成员的真实信息，只是提供了一个更方便交流的称呼。别名也是一样——`name` 还是 `name`，只是结果显示成了「学生姓名」。

::: tip 知识点
别名语法：`列名 [AS] 别名`。`AS` 可以省略；别名只在**本次查询的结果**中生效，不修改原始表。当列名是英文缩写或包含计算表达式时，别名能让结果更直观。
:::

### L4 常量和运算

**题目**：从 `student` 表中选择学生的姓名（name）和分数（score），并额外计算出分数的 2 倍，列名为 `double_score`。

**参考答案**：

```sql
select name, score, score * 2 as double_score from student;
```

**解析**：在 `SELECT` 中不仅可以直接列出列名，还可以写**表达式**。这里的 `score * 2` 对每一行的 `score` 做乘法运算，`2` 就是常量（固定的数值），运算结果作为新的一列输出。

表达式列通常搭配别名（`as double_score`）使用，否则结果集的列名会直接显示为 `score * 2` 这一长串表达式，既不美观也不易读。

::: tip 知识点
`SELECT` 支持常量与四则运算（`+`、`-`、`*`、`/` 等），运算基于每一行数据**逐行**进行，结果列建议用别名命名。常量和运算不仅限于数字，也可以对文本做拼接等字符串操作。
:::

### L5 条件查询 where

**题目**：从 `student` 表中选择姓名（name）和成绩（score），只保留姓名为 '鱼皮' 的学生。

**参考答案**：

```sql
select name, score from student where name = '鱼皮'
```

**解析**：前面的查询每次都返回整张表，而 `where` 子句让我们能**过滤行**：只有满足条件的数据行才会被返回。`where name = '鱼皮'` 中的 `=` 是比较运算符，判断 `name` 列的值是否等于字符串 `'鱼皮'`。

注意两个细节：一是字符串常量必须用**单引号**包裹，数字常量不用；二是 `where` 子句放在 `FROM` 之后、语句末尾（如果后面还有排序等子句，则放在它们之前）。

::: tip 知识点
`WHERE` 子句用于设置过滤条件，只返回满足条件的行。通用语法：

```sql
SELECT 列1, 列2, ...
FROM 表名
WHERE 条件;
```

条件中可以使用比较运算符（`=`、`<`、`>`）、逻辑运算符（`AND`、`OR`）、`IN`、`LIKE` 等。
:::

### L6 运算符

**题目**：从 `student` 表中选择姓名（name）和年龄（age），要求姓名不等于 '热dog'。

**参考答案**：

```sql
select name, age from student where name != '热dog'
```

**解析**：`where` 条件中可以使用各种**比较运算符**来做判断。`!=` 表示「不等于」，与 `=` 正好相反；除此之外还有 `>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于），以及判断范围用的 `BETWEEN ... AND ...`。

设想你是一名招聘官，表中的数据是面试候选人，运算符就是你设定的面试条件：用 `!=` 排除不符合要求的人，用 `>` 挑出成绩优秀的候选人，用 `BETWEEN` 筛选年龄在某个范围内的人。

::: tip 知识点
常用比较运算符：

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `=` | 等于 | `score = 100` |
| `!=` / `<>` | 不等于 | `name != '热dog'` |
| `>` `<` | 大于 / 小于 | `score > 500` |
| `>=` `<=` | 大于等于 / 小于等于 | `age >= 18` |
| `BETWEEN a AND b` | 在 [a, b] 范围内 | `age BETWEEN 18 AND 25` |
:::

### L7 空值

**题目**：从 `student` 表中选择姓名（name）、年龄（age）和成绩（score），要求年龄不为空值。

**参考答案**：

```sql
select name, age, score from student where age is not null
```

**解析**：数据库中的字段可能没有值，即**空值（NULL）**，表示「未知、不存在或未填写」。判断空值**不能**用 `= null` 或 `!= null`——NULL 与任何值比较结果都是未知的，必须使用专门的 `IS NULL` / `IS NOT NULL` 语法。

场景举例：你是考试老师，某个学生没参加考试或成绩还没出来，他的成绩就是 NULL。用 `IS NULL` 可以找出没参加考试的学生，用 `IS NOT NULL` 可以找出已经有成绩的学生。本题用 `age is not null` 过滤掉年龄为空的记录。

::: tip 知识点
空值判断：`列 IS NULL`（为空）、`列 IS NOT NULL`（不为空）。NULL 不等于 0，也不等于空字符串 `''`，它是「没有值」的特殊状态。
:::

### L8 模糊查询

**题目**：从 `student` 表中选择姓名（name）和成绩（score），要求姓名中不包含「李」字。

**参考答案**：

```sql
select name, score from student where name not like '%李%'
```

**解析**：精确匹配（`=`）无法满足「包含某个字」的需求，这时要用 `LIKE` 做**模糊查询**。`%` 通配符代表任意长度的任意字符序列，`'%李%'` 表示「名字中任意位置包含『李』字」；再在前面加上 `NOT` 取反，就得到「姓名中不包含『李』」的结果。

就像侦探破案：你只知道目标人物名字里有个「李」，用 `LIKE '%李%'` 就能根据这条线索把所有符合的人找出来。

::: tip 知识点
`LIKE` 模糊查询的两种通配符：
- `%`：匹配**任意长度**的字符序列（包括 0 个字符）
- `_`：匹配**任意单个**字符

`'李%'` 表示「李」开头，`'%李'` 表示「李」结尾，`'%李%'` 表示包含「李」。搭配 `NOT LIKE` 可排除匹配的行。
:::

### L9 逻辑运算

**题目**：从 `student` 表中选择姓名（name）和成绩（score），要求姓名包含「李」**或者**成绩大于 500。

**参考答案**：

```sql
select name, score from student where name like '%李%' or score > 500;
```

**解析**：一个 `where` 条件往往不够用，逻辑运算符可以把多个条件**组合**起来。`OR` 表示「或」，满足任意一个条件即返回该行——本题的结果是「姓李的学生」和「成绩超过 500 的学生」的并集。

逻辑运算符共有三个：`AND`（与，所有条件都满足才返回）、`OR`（或，满足任意一个即返回）、`NOT`（非，对条件取反）。当多个运算符混用时，建议用括号明确优先级，避免歧义。

::: tip 知识点
逻辑运算符：
- `AND`：逻辑与，多个条件**都满足**才返回 true
- `OR`：逻辑或，满足**任意一个**条件就返回 true
- `NOT`：逻辑非，否定一个条件（本来是 true，用 `NOT` 后变成 false）

例如：`where (name like '%李%' or score > 500) and age > 20` 表示「姓李或高分」**且**「年龄大于 20」。
:::

### L10 去重

**题目**：从 `student` 表中选择所有不重复的（班级 ID，考试编号）组合。

**参考答案**：

```sql
select distinct class_id, exam_num from student;
```

**解析**：数据表中可能存在重复记录，`DISTINCT` 关键字用于**去重**：它会去掉结果集中完全相同的行，只保留不同的记录。

注意 `DISTINCT` 作用于 `SELECT` 后面**所有列的组合**——本题是对 `(class_id, exam_num)` 这个二元组去重：只有班级 ID 和考试编号**同时相同**的行才会被合并，而不是分别对两列单独去重。

::: tip 知识点
`SELECT DISTINCT 列1, 列2 FROM 表名` 会对所选列**组合**去重，组合完全相同才算重复。场景举例：班长想统计班里有哪几种不同的「班级 + 考试」组合，而不关心每个组合出现了多少次，就用 `DISTINCT`。
:::

### L11 排序

**题目**：从 `student` 表中选择姓名（name）、年龄（age）和成绩（score），先按成绩**从大到小**排序，成绩相同则按年龄**从小到大**排序。

**参考答案**：

```sql
select name, age, score from student order by score desc, age asc;
```

**解析**：`ORDER BY` 对查询结果进行排序，放在语句末尾。`DESC` 表示降序（从大到小），`ASC` 表示升序（从小到大，也是默认值，可以省略不写）。

多个排序字段用逗号分隔，**从左到右依次生效**：先按 `score` 降序排，`score` 相同时再按 `age` 升序排。这样就实现了「成绩高者在前，同分时年龄小者在前」的效果。

::: tip 知识点
排序语法：`ORDER BY 列1 [ASC|DESC], 列2 [ASC|DESC]`。
- `ASC`：升序（默认，可省略）
- `DESC`：降序（必须写明）

排序字段的优先级从左到右递减，先满足前面的排序规则，再处理后面的。
:::

### L12 截断和偏移

**题目**：从 `student` 表中选择姓名（name）和年龄（age），按年龄从小到大排序，从第 2 条数据开始截取 3 个学生。

**参考答案**：

```sql
select name, age from student order by age asc limit 1, 3;
```

**解析**：`LIMIT` 用来控制返回的行数，实现「截断」和「偏移」。`limit 1, 3` 中的第一个数字 `1` 是**偏移量（offset）**，表示跳过前 1 条；第二个数字 `3` 是**返回行数**。注意偏移量从 0 开始计数，所以偏移 1 意味着从第 2 条数据开始取。

可以这样理解：你有一张待办事项清单，只想每次看其中的几项——用手指挡住不需要看的部分就是「截断」，按编号直接翻到想看的位置就是「偏移」。这种「跳过 N 条、取 M 条」的写法是**分页**的核心实现。

::: tip 知识点
`LIMIT 偏移量, 行数`：
- 偏移量从 0 开始（偏移 0 即从头取起）
- 行数是要返回的记录条数

等价写法：`LIMIT 行数 OFFSET 偏移量`，例如 `limit 3 offset 1` 与 `limit 1, 3` 效果相同。网站分页时「第 2 页每页 10 条」就对应 `limit 10, 10`。
:::

### L13 条件分支

**题目**：将学生按年龄划分为三个等级（age_level）：60 岁以上为「老同学」，20 岁以上（不含 60 岁以上）为「年轻」，20 岁及以下以及没有年龄信息的为「小同学」。返回姓名和年龄等级，并按姓名升序排序。

**参考答案**：

```sql
SELECT
  name,
  CASE WHEN (age > 60) THEN '老同学'
       WHEN (age > 20) THEN '年轻'
       ELSE '小同学' END AS age_level
FROM
  student
ORDER BY
  name asc;
```

**解析**：`CASE WHEN ... THEN ... ELSE ... END` 是 SQL 中的**条件分支**语法，类似编程语言里的 `if / else if / else`，可以根据条件在查询结果中动态生成新列。条件从上到下依次判断，**命中第一个满足的条件后就不再往下判断**：先看是否大于 60，再看是否大于 20，都不满足则落入 `ELSE`。

本题的 `ELSE` 分支天然覆盖了「20 岁及以下」和「无年龄信息（NULL）」两种情况——因为 NULL 不会满足任何比较条件，会直接落入 `ELSE`。最后用 `ORDER BY name asc` 按姓名升序输出。就像餐厅服务员根据客人点的菜（鱼、牛排……）选择不同的服务方式，`CASE WHEN` 根据不同的数据值返回不同的结果。

::: tip 知识点
条件分支语法：

```sql
CASE
  WHEN 条件1 THEN 结果1
  WHEN 条件2 THEN 结果2
  ...
  ELSE 默认结果
END [AS 别名]
```

- 按顺序匹配**第一个成立**的条件，后面的不再判断
- 都不成立时返回 `ELSE` 的值（`ELSE` 可省略，省略时返回 NULL）
- NULL 不满足任何比较条件，会直接落入 `ELSE`
:::

## 本章小结

到这里，SQL 基础语法篇（L1 ~ L13）就全部学完了。回顾一下这一章的核心语法：

| 关卡 | 语法点 | 关键字 |
|------|--------|--------|
| L1 ~ L2 | 全表查询 / 选择查询 | `SELECT ... FROM ...` |
| L3 | 别名 | `AS` |
| L4 | 常量和运算 | 表达式 |
| L5 ~ L9 | 条件查询 | `WHERE`、比较运算符、`IS NULL`、`LIKE`、`AND/OR/NOT` |
| L10 | 去重 | `DISTINCT` |
| L11 | 排序 | `ORDER BY ... ASC/DESC` |
| L12 | 截断和偏移 | `LIMIT 偏移量, 行数` |
| L13 | 条件分支 | `CASE WHEN ... THEN ... ELSE ... END` |

这些语法是 SQL 查询的地基，后面的「函数」「分组聚合」「关联查询」等进阶内容，全部建立在这些基础之上。建议把每一关的 SQL 都亲自敲一遍，再试着组合使用——比如「用 `WHERE` 过滤 + `ORDER BY` 排序 + `LIMIT` 分页」，你已经能写出不少真实场景下的查询了。
