### L14 时间函数

**场景**：学生表 `student`（字段 `name`、`age`），查询所有学生的姓名和当前日期（列名 `当前日期`）。

**参考答案**：

```sql
select name, date() as 当前日期 from student;
```

**解析**：核心知识点是**时间函数**。时间函数用于处理日期和时间数据，可在查询中直接获取或操作日期时间，无需手工拼接字符串。`date()` 返回**当前日期**（只含年月日），通过 `as` 取别名 `当前日期`，与 `name` 一起作为结果的两列返回。`date()` 不带参数时即表示「获取当前日期」。

**常用时间函数**：

| 函数 | 说明 | 示例 |
|------|------|------|
| `date()` | 获取当前日期（年月日） | `date()` → `2025-08-07` |
| `time()` | 获取当前时间（时分秒） | `time()` → `10:23:45` |
| `datetime()` | 获取当前日期和时间 | `datetime()` → `2025-08-07 10:23:45` |
| `now()` | 获取当前日期时间（MySQL 等数据库） | `now()` → `2025-08-07 10:23:45` |
| `current_timestamp` | 当前时间戳，等价于 now() | `current_timestamp` |
| `strftime(格式, 日期)` | 按指定格式提取/格式化日期 | `strftime('%Y-%m', date())` → `2025-08` |
| `julianday(日期)` | 将日期转换为天数，可用于日期差值计算 | `julianday('2025-08-07') - julianday('2025-08-01')` → `6` |

::: note
不同数据库（MySQL、SQLite、PostgreSQL 等）的时间函数名称略有差异，核心思想一致：**获取当前时间** 和 **对时间做格式化与运算**。`date()` / `time()` / `datetime()` 是 SQLite 风格，`now()` 是 MySQL 风格，按题目要求的数据库选择。
:::

**相关示例**：时间函数常用于「今日数据统计」「最近 7 天订单」等业务场景，例如：

```sql
-- 统计 2025 年 8 月 1 日之后注册的学生
select name from student where date(register_time) > '2025-08-01';
```

::: tip
日期比较时，先用 `date()` 等函数把时间字段「截断」到日，避免时分秒差异影响比较结果。
:::

### L15 字符串处理

**场景**：学生表 `student`（字段 `id`、`name`），筛选姓名为 `热dog` 的学生，展示学号、姓名及其大写姓名（`upper_name`）。

**参考答案**：

```sql
SELECT id, name, UPPER(name) AS upper_name
FROM student
WHERE name = '热dog';
```

**解析**：该查询结合了**条件查询 + 字符串函数**。先用 `WHERE name = '热dog'` 筛选出目标学生，再用 `UPPER(name)` 将姓名转换为**全大写**，通过 `AS upper_name` 为这一列命名。核心知识点是**字符串处理函数**——处理文本数据的函数，支持大小写转换、取长度、截取、替换等操作。

**常用字符串处理函数**：

| 函数 | 说明 | 示例 |
|------|------|------|
| `upper(str)` | 将字符串转换为大写 | `upper('dog')` → `DOG` |
| `lower(str)` | 将字符串转换为小写 | `lower('DOG')` → `dog` |
| `length(str)` | 返回字符串的长度 | `length('hello')` → `5` |
| `substr(str, start, len)` | 从指定位置截取子串 | `substr('hello', 2, 3)` → `ell` |
| `trim(str)` | 去除字符串两端的空格 | `trim('  hi  ')` → `hi` |
| `replace(str, 旧, 新)` | 将字符串中的子串替换为新内容 | `replace('a-b-c', '-', '_')` → `a_b_c` |
| `concat(a, b)` | 拼接多个字符串 | `concat('鱼', '皮')` → `鱼皮` |
| `instr(str, 子串)` | 查找子串第一次出现的位置 | `instr('hello', 'l')` → `3` |

::: tip
字符串函数可**嵌套**使用，例如 `upper(trim(name))` 表示先去除两端空格、再转为大写。真实业务中清洗用户输入数据时常使用这种组合写法。
:::

**相关示例**：字符串处理是数据清洗的基础，几个高频组合写法：

```sql
-- 1. 去除姓名两端空格后转大写
select upper(trim(name)) from student;

-- 2. 截取手机号中间 4 位做脱敏展示
select concat(substr(phone, 1, 3), '****', substr(phone, 8, 4)) from student;

-- 3. 把成绩单中的 '-' 占位符替换为 0
select replace(score_text, '-', '0') from student;
```

::: warning
`substr` 的起始位置从 **1** 开始计数（而非编程语言中常见的 0），截取时容易差一位。
:::

### L16 聚合函数

**场景**：学生表 `student`（字段 `id`、`name`、`class_id`、`score`），汇总所有学生的总成绩、平均成绩、最高成绩和最低成绩。

**参考答案**：

```sql
SELECT
  SUM(score) AS total_score,
  AVG(score) AS avg_score,
  MAX(score) AS max_score,
  MIN(score) AS min_score
FROM
  student;
```

**解析**：核心知识点是**聚合函数**。聚合函数对一组数据进行**汇总计算**，把多行数据「压缩」成一个结果。`SUM(score)` 计算成绩总和，`AVG(score)` 计算平均值，`MAX(score)` 和 `MIN(score)` 分别找出最高分和最低分。聚合函数作用于**整列数据**而非单行，因此该查询不写 `WHERE` 条件，直接对全表 `student` 汇总，返回一行汇总结果。

**常用聚合函数**：

| 函数 | 说明 | 示例 |
|------|------|------|
| `count(*)` | 计算行数（含 NULL 行） | `count(*)` → 学生总数 |
| `count(列名)` | 计算该列非空值的数量 | `count(score)` → 有成绩的人数 |
| `sum(列名)` | 计算数值列的总和 | `sum(score)` → 总成绩 |
| `avg(列名)` | 计算数值列的平均值 | `avg(score)` → 平均成绩 |
| `max(列名)` | 找出列中的最大值 | `max(score)` → 最高分 |
| `min(列名)` | 找出列中的最小值 | `min(score)` → 最低分 |

::: warning
`SUM` 和 `AVG` 只能用于数值类型的列；`COUNT`、`MAX`、`MIN` 也可用于文本列（如统计姓名个数、找字典序最大/最小的名字）。聚合函数会**忽略 NULL 值**（`COUNT(*)` 除外），统计时需注意。
:::

::: note
聚合函数经常与 `GROUP BY` 搭配使用，实现「按组汇总」——例如按班级分组统计每个班的平均分。下一章「分组聚合」详细介绍。
:::

## 本章小结

函数让 SQL 从「查数据」升级为「加工数据」。三关的核心内容：

| 关卡 | 函数类别 | 代表函数 | 典型场景 |
|------|----------|----------|----------|
| L14 | 时间函数 | `date()` `time()` `datetime()` `now()` | 记录创建时间、统计今日/本周数据 |
| L15 | 字符串处理 | `upper()` `lower()` `length()` `substr()` `trim()` `replace()` `concat()` | 大小写转换、截取脱敏、清洗脏数据 |
| L16 | 聚合函数 | `count()` `sum()` `avg()` `max()` `min()` | 成绩汇总、订单总额、排行榜极值 |

**速记口诀**：

- **时间函数**——要当前时间，`date()` / `time()` / `datetime()` / `now()` 按需取；
- **字符串函数**——大小写用 `upper` / `lower`，长度用 `length`，截取用 `substr`，清洗用 `trim` / `replace`，拼接用 `concat`；
- **聚合函数**——汇总一行出结果：计数 `count`、求和 `sum`、平均 `avg`、最大 `max`、最小 `min`。

::: important
三种函数的侧重点不同：时间函数和字符串函数对**每一行**分别加工（逐行处理），聚合函数把**多行压缩成一行**（整体汇总）。写 SQL 前先想清楚：需要的是「每行的新值」还是「整组的一个汇总值」？
:::
