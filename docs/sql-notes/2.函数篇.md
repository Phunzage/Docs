## 本章概览

函数是 SQL 中用来**加工和处理数据**的利器。如果说 `SELECT` / `WHERE` 决定了我们「查哪些数据」，那么函数则决定了这些数据在返回给我们之前要经过怎样的「加工」。

举个例子：学生表里存的是 `2025-08-07 10:23:45` 这样的原始时间，但页面上只想展示 `08-07`；姓名存的是 `dog`，但打印名单时要显示成大写 `DOG`；想看全班平均分，总不能一行行自己算——这些场景统统交给函数解决。

本章共 3 关，从三个最常见的维度带你认识 SQL 函数：

| 关卡 | 主题 | 核心内容 |
|------|------|----------|
| L14 | 时间函数 | DATE / TIME / DATETIME / NOW 等日期时间处理 |
| L15 | 字符串处理 | UPPER / LOWER / LENGTH / SUBSTR 等文本加工 |
| L16 | 聚合函数 | SUM / AVG / MAX / MIN / COUNT 汇总计算 |

::: tip
函数可以出现在 `SELECT` 子句中（对查询结果做加工），也可以配合 `WHERE` 条件使用（如 L15 先筛选再转换），用法非常灵活。
:::

### L14 时间函数

**题目**：假设有一个学生表 `student`，包含以下字段：`name`（姓名）、`age`（年龄）。请你编写一个 SQL 查询，展示所有学生的姓名（name）和当前日期（列名为 `当前日期`）。

**参考答案**：

```sql
select name, date() as 当前日期 from student;
```

**解析**：本题的核心是**时间函数**。时间函数用于处理日期和时间数据，让我们能在查询中直接获取或操作日期时间，而不必自己拼字符串。`date()` 会返回**当前日期**（只含年月日），通过 `as` 把它取别名为 `当前日期`，与 `name` 一起作为查询结果的两列返回。注意 `date()` 不带任何参数时，就表示「获取当前日期」。

**常用时间函数**：

| 函数 | 说明 | 示例 |
|------|------|------|
| `date()` | 获取当前日期（年月日） | `date()` → `2025-08-07` |
| `time()` | 获取当前时间（时分秒） | `time()` → `10:23:45` |
| `datetime()` | 获取当前日期和时间 | `datetime()` → `2025-08-07 10:23:45` |
| `now()` | 获取当前日期时间（MySQL 等数据库） | `now()` → `2025-08-07 10:23:45` |
| `current_timestamp` | 当前时间戳，等价于 now() | `current_timestamp` |
| `strftime(格式, 日期)` | 按指定格式提取/格式化日期 | `strftime('%Y-%m', date())` → `2025-08` |
| `julianday(日期)` | 将日期转换为天数，可用于日期差值计算 | `julianday('2025-08-07') - julianday('2025-08-01')` → `6` |

::: note
不同数据库（MySQL、SQLite、PostgreSQL 等）的时间函数名称略有差异，但核心思想一致：**获取当前时间** 和 **对时间做格式化与运算**。`date()` / `time()` / `datetime()` 是 SQLite 风格，`now()` 是 MySQL 风格，写题时按题目要求的数据库选择即可。
:::

**举一反三**：时间函数常用于业务中的「今日数据统计」「最近 7 天订单」等场景，例如：

```sql
-- 统计 2025 年 8 月 1 日之后注册的学生
select name from student where date(register_time) > '2025-08-01';
```

::: tip
遇到日期比较时，推荐先用 `date()` 等函数把时间字段「截断」到日，避免时分秒的差异影响比较结果。
:::

### L15 字符串处理

**题目**：假设有一个学生表 `student`，包含以下字段：`id`（学号）、`name`（姓名）。请你编写一个 SQL 查询，筛选出姓名为 `热dog` 的学生，展示其学号（id）、姓名（name）及其大写姓名（upper_name）。

**参考答案**：

```sql
SELECT id, name, UPPER(name) AS upper_name
FROM student
WHERE name = '热dog';
```

**解析**：本题综合考察了**条件查询 + 字符串函数**。先用 `WHERE name = '热dog'` 筛选出目标学生；再用字符串函数 `UPPER(name)` 把姓名转换成**全大写**，并通过 `AS upper_name` 为这一列命名。这里的核心知识点是**字符串处理函数**——它们是处理文本数据的函数，可以对字符串进行大小写转换、取长度、截取、替换等操作。

**常用字符串处理函数**：

| 函数 | 说明 | 示例 |
|------|------|------|
| `upper(str)` | 将字符串转换为大写 | `upper('dog')` → `DOG` |
| `lower(str)` | 将字符串转换为小写 | `lower('DOG')` → `dog` |
| `length(str)` | 返回字符串的长度 | `length('hello')` → `5` |
| `substr(str, start, len)` | 从指定位置截取子串 | `substr('hello', 2, 3)` → `ell` |
| `trim(str)` | 去除字符串两端的空格 | `trim('  hi  ')` → `hi` |
| `replace(str, 旧, 新)` | 将字符串中的子串替换为新内容 | `replace('a-b-c', '-', '_')` → `a_b_c` |
| `concat(a, b)` | 拼接多个字符串 | `concat('鱼', '皮')` → `鱼皮` |
| `instr(str, 子串)` | 查找子串第一次出现的位置 | `instr('hello', 'l')` → `3` |

::: tip
字符串函数可以**嵌套**使用，例如 `upper(trim(name))` 表示先去除两端空格、再转为大写。在真实业务中，清洗用户输入数据时经常用到这种组合写法。
:::

**举一反三**：字符串处理是数据清洗的基石，几个高频组合写法：

```sql
-- 1. 去除姓名两端空格后转大写
select upper(trim(name)) from student;

-- 2. 截取手机号中间 4 位做脱敏展示
select concat(substr(phone, 1, 3), '****', substr(phone, 8, 4)) from student;

-- 3. 把成绩单中的 '-' 占位符替换为 0
select replace(score_text, '-', '0') from student;
```

::: warning
`substr` 的起始位置从 **1** 开始计数（而非编程语言中常见的 0），截取时注意别差一位。
:::

### L16 聚合函数

**题目**：假设有一个学生表 `student`，包含以下字段：`id`（学号）、`name`（姓名）、`class_id`（班级编号）、`score`（成绩）。请你编写一个 SQL 查询，汇总学生表中所有学生的总成绩（total_score）、平均成绩（avg_score）、最高成绩（max_score）和最低成绩（min_score）。

**参考答案**：

```sql
SELECT
  SUM(score) AS total_score,
  AVG(score) AS avg_score,
  MAX(score) AS max_score,
  MIN(score) AS min_score
FROM
  student;
```

**解析**：本题的核心是**聚合函数**。聚合函数用于对一组数据进行**汇总计算**——它把多行数据「压缩」成一个结果。`SUM(score)` 计算所有学生成绩的总和，`AVG(score)` 计算平均值，`MAX(score)` 和 `MIN(score)` 分别找出最高分和最低分。注意：聚合函数作用于**整列数据**，而不是单行，所以本题不写 `WHERE` 条件，直接对全表 `student` 汇总，返回一行汇总结果。

**常用聚合函数**：

| 函数 | 说明 | 示例 |
|------|------|------|
| `count(*)` | 计算行数（含 NULL 行） | `count(*)` → 学生总数 |
| `count(列名)` | 计算该列非空值的数量 | `count(score)` → 有成绩的人数 |
| `sum(列名)` | 计算数值列的总和 | `sum(score)` → 总成绩 |
| `avg(列名)` | 计算数值列的平均值 | `avg(score)` → 平均成绩 |
| `max(列名)` | 找出列中的最大值 | `max(score)` → 最高分 |
| `min(列名)` | 找出列中的最小值 | `min(score)` → 最低分 |

::: warning
`SUM` 和 `AVG` 只能用于数值类型的列；`COUNT`、`MAX`、`MIN` 也可以用于文本列（如统计姓名个数、找字典序最大/最小的名字）。另外，聚合函数会**忽略 NULL 值**（`COUNT(*)` 除外），统计时要注意。
:::

::: note
聚合函数经常和 `GROUP BY` 搭配使用，实现「按组汇总」——例如按班级分组统计每个班的平均分。下一章「分组聚合」会详细介绍。
:::

## 本章小结

函数让 SQL 从「查数据」升级为「加工数据」。回顾一下三关的核心内容：

| 关卡 | 函数类别 | 代表函数 | 典型场景 |
|------|----------|----------|----------|
| L14 | 时间函数 | `date()` `time()` `datetime()` `now()` | 记录创建时间、统计今日/本周数据 |
| L15 | 字符串处理 | `upper()` `lower()` `length()` `substr()` `trim()` `replace()` `concat()` | 大小写转换、截取脱敏、清洗脏数据 |
| L16 | 聚合函数 | `count()` `sum()` `avg()` `max()` `min()` | 成绩汇总、订单总额、排行榜极值 |

**速记口诀**：

- **时间函数**——要当前时间，`date()` / `time()` / `datetime()` / `now()` 按需取；
- **字符串函数**——大小写用 `upper` / `lower`，长度用 `length`，截取用 `substr`，清洗用 `trim` / `replace`，拼接用 `concat`；
- **聚合函数**——汇总一行出结果：计数 `count`、求和 `sum`、平均 `avg`、最大 `max`、最小 `min`。

::: important
三种函数的侧重点不同：时间函数和字符串函数是对**每一行**分别加工（逐行处理），而聚合函数是把**多行压缩成一行**（整体汇总）。写 SQL 前先想清楚：我要的是「每行的新值」还是「整组的一个汇总值」？
:::

下一章我们将学习聚合函数的最佳搭档——`GROUP BY` 分组聚合，学会按班级、按考试等维度进行分组统计。
