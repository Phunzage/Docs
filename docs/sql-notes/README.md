## 学习建议

- 每篇笔记包含：**题目描述 → 参考答案 → 知识点解析**
- 建议先独立尝试作答，再看答案
- 掌握 L1-L19（基础语法 + 函数 + 分组聚合）后，即可应对大部分日常查询需求
- L20-L30（关联查询、子查询、开窗函数）是进阶重点，面试高频
