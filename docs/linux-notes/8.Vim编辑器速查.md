Vim 编辑器有三种主要模式：**一般模式**、**编辑模式**、**命令行模式**。

## 一般模式常用操作

### 复制粘贴

| 命令 | 说明 |
|:----:|------|
| `yy` | 复制当前行 |
| `nyy` | 向下复制 n 行（n 为数字） |
| `p` | 在光标所在行下方粘贴 |

### 删除

| 命令 | 说明 |
|:----:|------|
| `dd` | 删除当前行 |
| `ndd` | 向下删除 n 行（n 为数字） |

### 光标移动

| 命令 | 说明 |
|:----:|------|
| `0` | 移动到行首 |
| `$` | 移动到行尾 |
| `gg` | 移动到文件第一行 |
| `G` | 移动到文件最后一行 |
| `nG` | 移动到第 n 行 |
| `:n` | 跳转到第 n 行 |

### 撤销与重做

| 命令 | 说明 |
|:----:|------|
| `u` | 撤销上一步操作 |
| `Ctrl + r` | 重做（恢复撤销） |

## 编辑模式

| 命令 | 说明 |
|:----:|------|
| `i` | 在光标前插入 |
| `a` | 在光标后插入 |
| `o` | 在光标所在行下方插入新行 |
| `Esc` | 返回一般模式 |

## 命令行模式

| 命令 | 说明 |
|:----:|------|
| `:w` | 保存文件 |
| `:q` | 退出 Vim |
| `:wq` | 保存并退出 |
| `:q!` | 强制退出不保存 |
| `:set nu` | 显示行号 |
| `:set nonu` | 取消行号 |
| `/关键词` | 向下搜索关键词 |
| `?关键词` | 向上搜索关键词 |
| `n` | 重复上一次搜索（下一个匹配） |
| `N` | 反向重复上一次搜索（上一个匹配） |
| `:%s/旧词/新词/g` | 全文替换 |
| `:nohl` | 取消搜索高亮 |
