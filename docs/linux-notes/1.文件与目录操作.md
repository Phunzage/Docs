## 目录切换

| 命令 | 说明 |
|------|------|
| `cd ..` | 进入上级目录 |
| `cd ~` 或 `cd` | 进入当前用户的家目录（root → `/root`，普通用户 → `/home/用户名`） |

## 查看目录内容

| 命令 | 说明 |
|------|------|
| `ls` | 显示当前目录下所有文件 |
| `ls -a` | 显示隐藏文件（以 `.` 开头的文件） |
| `ls -l` | 以单列方式显示详细文件信息（可简写为 `ll`） |
| `ls -al` / `ls -la` | 组合使用，显示所有文件的详细信息 |
| `ls -lh` | 以人类可读的格式显示（如将字节显示为 MB） |
| `ls /目录名 -al` | 显示**指定目录**下的所有文件 |

## 路径操作

| 命令 | 说明 |
|------|------|
| `pwd` | 显示当前所在目录的绝对路径 |

## 创建目录

| 命令 | 说明 |
|------|------|
| `mkdir 目录名` | 创建一级目录 |
| `mkdir -p 目录1/目录2/目录3` | 递归创建多级目录 |

## 删除目录

| 命令 | 说明 |
|------|------|
| `rmdir 目录名` | 删除空目录 |
| `rm -r 目录名` | 递归删除有内容的目录 |

::: tip
Linux 下，**目录 ≈ 文件夹**，**文件**即单个有扩展名的文件。
:::

## 创建文件

| 命令 | 说明 |
|------|------|
| `touch 文件名` | 创建新文件 |

## 拷贝

| 命令 | 说明 |
|------|------|
| `cp 源文件 目标目录` | 拷贝文件到指定目录 |
| `cp -r 源目录 目标目录` | 拷贝整个目录到目标目录 |
| `\cp 源文件 目标目录` | **强制覆盖**不提示（适用于目标目录已有同名文件） |

## 删除

| 命令 | 说明 |
|------|------|
| `rm 文件名` | 删除文件 |
| `rm -f 文件名` | 强制删除不提示 |
| `rm -r 目录名` | 递归删除整个目录 |
| `rm -rf 目录名` | 强制递归删除整个目录（⚠️ 谨慎使用） |

::: danger
`rm -rf` 是危险命令，使用前务必确认路径正确！
:::

## 移动与重命名

| 命令 | 说明 |
|------|------|
| `mv 旧文件名 新文件名` | 重命名文件或目录 |
| `mv 原路径 新路径` | 移动文件或目录 |
| `mv 原路径/文件 新路径/新名称` | 边移动边重命名 |

## 符号链接（快捷方式）

| 命令 | 说明 |
|------|------|
| `ln -s 目标文件 链接名` | 创建软连接（符号链接） |

> [!NOTE]
> 软连接类似 Windows 的快捷方式，删除原文件后链接会失效。
