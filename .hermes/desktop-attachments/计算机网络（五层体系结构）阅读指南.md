# 计算机网络（五层体系结构）阅读指南



> 阅读建议：先阅读应用层 → 传输层 → 网络层 → 数据链路层 → 物理层。不要试图一次记住所有协议，而应关注“数据从浏览器发送到服务器”这一主线流程。掌握 DNS、HTTP、TCP、IP、ARP 五个核心知识点后，再深入学习 HTTPS、路由协议、CDN、VPN 等现代互联网技术。



## 一、推荐观看顺序

不要按照考试背诵方式阅读，而是按照数据传输过程阅读。

推荐顺序：

```text
应用层
 ↓
传输层
 ↓
网络层
 ↓
数据链路层
 ↓
物理层
```

可以想象这样一个场景：

```text
浏览器输入 www.baidu.com

↓ 应用层
DNS解析
HTTP请求

↓ 传输层
TCP建立连接

↓ 网络层
IP寻址和路由

↓ 数据链路层
封装成帧

↓ 物理层
转换成电信号发送
```

服务器收到后再反向解封装。

只要理解这一过程，整个计算机网络体系结构就建立起来了。

------

## 二、每层最重要的问题

阅读时不要死记硬背协议名称。

尝试回答下面五个问题：

| 层次       | 核心问题                 |
| ---------- | ------------------------ |
| 应用层     | 我要访问什么服务？       |
| 传输层     | 数据如何可靠送达？       |
| 网络层     | 数据发往哪里？           |
| 数据链路层 | 数据如何在当前网络传输？ |
| 物理层     | 数据如何变成信号？       |

如果能回答这五个问题，就已经理解了五层模型。

------

## 三、新手重点关注内容

第一次学习建议重点掌握：

### 应用层

- DNS
- HTTP
- HTTPS

原因：

每天都在使用。

打开网页就会经历：

```text
DNS
↓
TCP
↓
HTTPS
```

------

### 传输层

重点：

- TCP
- UDP

理解：

```text
TCP = 打电话

确认对方收到
保证顺序

UDP = 喊话

快
但不保证收到
```

这是整个网络课程最重要的知识点之一。

------

### 网络层

重点：

- IP地址
- 路由器
- NAT

理解：

```text
IP = 家庭住址

路由器 = 快递中转站
```

当理解路由转发后，互联网的本质就明白了一半。

------

### 数据链路层

重点：

- MAC地址
- 交换机
- ARP

理解：

```text
IP负责找城市

MAC负责找具体设备
```

------

### 物理层

重点：

- 比特流
- 编码
- 光纤
- 双绞线

理解即可，不必深究电路细节。

------

## 四、全图最难的部分

对于初学者来说：

### 第一难点：TCP

重点理解：

- 三次握手
- 四次挥手
- 流量控制
- 拥塞控制

建议：

先理解为什么要握手。

再理解握手过程。

最后学习各种机制。

------

### 第二难点：路由

重点理解：

- 路由表
- CIDR
- BGP
- 默认网关

建议：

先理解：

```text
路由器如何决定下一跳
```

再学习各种路由协议。

------

### 第三难点：HTTPS

重点理解：

```text
为什么不用对称加密？

为什么不用非对称加密？

为什么两者结合？
```

理解这个问题后：

- TLS
- 数字证书
- CA

都会容易很多。

------

## 五、学习路线建议

### 第一遍

目标：

```text
知道每层干什么
```

不追求细节。

------

### 第二遍

目标：

```text
掌握主要协议
```

重点：

- HTTP
- DNS
- TCP
- UDP
- IP
- ARP

------

### 第三遍

目标：

```text
理解真实互联网如何运行
```

重点：

- NAT
- DHCP
- VPN
- CDN
- HTTP/3
- WebSocket
- BGP

------

## 六、一句话理解整张图

```text
应用层决定做什么，
传输层决定怎么传，
网络层决定传给谁，
数据链路层决定本地怎么传，
物理层决定如何发送信号。
```

记住这句话，再回头看思维导图，整个计算机网络体系结构会清晰很多。
